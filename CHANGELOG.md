- Add portable setup, binding, evidence review, and task retrieval for explanatory
  working principles. Include templates for personal-memory and maintenance loops.

  embedded Git checkouts outside their parent repository's documentation intake.

  and the limits of maintenance checks.

  preserves existing installations by refusing to overwrite them.

  is not implemented in this release.
